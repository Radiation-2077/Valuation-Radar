# 估值雷达

本机优先的估值分析 Web 应用。项目把现有估值数据卡、三套风险偏好排名和估值报告升级为可查询、可追溯、可定时更新的产品。

## 当前状态

- 架构与阶段计划：`docs/DEVELOPMENT_PLAN.md`
- 前端：Vue 3 + TypeScript + Vite
- 后端：FastAPI + SQLAlchemy + SQLite
- 数据源：上级目录的 `data/`、`common/` 和估值 HTML
- 自动更新：收盘后行情刷新、排名重算、按事件触发的 Codex 重估

当前仓库按阶段迭代。已完成能力以 `git log` 和项目文档为准，不在 README 中维护易失真的完成度。

## 开发原则

1. 历史估值报告不可原地修改，修订创建新版本。
2. 模型输出先进入隔离目录，通过 schema、公式和来源校验后才能入库。
3. 自动任务失败时保留最近一次可信数据。
4. 每个阶段通过测试后再提交，提交信息由 `git-commit-message` skill 生成。

## 数据说明

本项目的默认导入源是仓库上级目录：

```text
../data/*.json
../common/*.json
../*_估值分析_*.html
```

运行时数据库、日志和归档报告不提交到 Git。所有分析结果仅用于研究，不构成投资建议。
