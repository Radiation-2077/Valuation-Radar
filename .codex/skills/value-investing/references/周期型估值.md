# 周期型估值

> 阶段三B 参考文档。适用条件：利润波动大（年波动 > 30%）、与宏观强相关、有明确的行业周期。

---

## 前提：必须通过质地判断

周期型投资的核心逻辑：**在低谷买入好公司，熬到景气回升。** 如果公司质地差、熬不过去 → 不是机会，是陷阱。

先确认：
- [ ] 有息负债率 < 50%（杠杆不高，能扛过寒冬）
- [ ] 经济危机年份（2020/2022）依然盈利或亏损可控
- [ ] 是行业成本最低的生产者之一（成本优势 = 活下去的资本）

---

## 步骤 1：判断周期位置

综合以下信号，不要依赖单一指标：

| 信号 | 底部特征 | 顶部特征 | 当前状态 |
|:---|:---|:---|:---|
| **行业利润** | 全行业亏损/微利 | 全行业暴利 | |
| **产能** | 小厂倒闭、产能出清 | 大家都在扩产、新进入者涌入 | |
| **库存** | 去库存尾声、库存低位 | 库存高企、经销商压货 | |
| **资本开支** | 企业缩减投资、取消项目 | 大笔 CAPEX、争抢产能 | |
| **情绪/媒体** | "这个行业完了" | "这次不一样"、"超级周期" | |
| **时间维度** | 下行已持续 2-3 年 | 上行已持续 2-3 年 | |

### 综合判断

```
周期位置：□ 底部区间  □ 中部偏下  □ 中部  □ 中部偏上  □ 顶部区间
```

> **底部是一个区间，不是一个点。** 在底部区间分批买入，比等待"最低点"更现实。

---

## 步骤 2：正常化利润 PE

### 公式

$$正常化PE = \frac{当前市值}{过去5-10年平均扣非净利润}$$

### 操作

| 年份 | 扣非净利润（亿） | 备注 |
|:---|:---:|:---|
| Y-9 | | |
| Y-8 | | |
| ... | | |
| 今年 | | |

**5 年平均净利润** = ______ 亿（覆盖了至少一个完整周期吗？是/否）
**10 年平均净利润** = ______ 亿

> 如果 5 年已覆盖完整周期，用 5 年。如果周期特别长（航运、有色等），用 10 年。

$$正常化PE = \frac{市值}{\text{平均净利润}} = \frac{\_\_\_\_\_\_}{\_\_\_\_\_\_} = \_\_\_\_\_\_ 倍$$

### 判断标准

| 正常化 PE | 含义 |
|:---|:---|
| < 8 倍 | 深度低估 |
| 8-12 倍 | 低估 |
| 12-18 倍 | 合理 |
| 18-25 倍 | 偏贵 |
| > 25 倍 | 高估 |

注意：中枢因行业和利率环境而异。重资产行业（钢铁、水泥）中枢偏低（10-15×），轻资产周期行业中枢偏高。

---

## 步骤 3：PB 历史分位

重资产周期公司的净资产（厂房、设备、土地）比利润更稳定，PB 往往比 PE 更可靠。

$$PB = \frac{市值}{净资产}$$

| PB 水平 | 含义 |
|:---|:---|
| < 0.8 + 历史底部 20% 分位 | 深度折价 |
| 0.8-1.2 | 合理 |
| > 1.5 + 历史顶部 20% 分位 | 偏贵 |

### PB 盲区警告

> PB < 1 不等于低估。如果资产已经过时/减值/无法产生利润，那账面资产确实不值钱。
>
> **PB 必须和 ROE 一起看**：
> - PB 低 + ROE 有望恢复 → 真机会
> - PB 低 + ROE 永远回不去 → 价值陷阱

---

## 步骤 4：EV/EBITDA 验证

排除折旧政策差异，适合重资产公司横向对比。

$$EV = 市值 + 有息负债 - 现金$$
$$EBITDA = 净利润 + 所得税 + 利息 + 折旧 + 摊销$$

| EV/EBITDA | 含义（周期行业） |
|:---|:---|
| < 6 倍 | 低估 |
| 6-10 倍 | 合理 |
| > 12 倍 | 偏贵 |

---

## 综合判断

三个指标指向同一方向时信号最可靠：

| 指标 | 当前值 | 基准 | 信号 |
|:---|:---:|:---|:---|
| 正常化 PE | \_\_ 倍 | 行业中枢 \_\_ 倍 | 低估/合理/高估 |
| PB | \_\_ 倍 | 历史 \_\_ 分位 | 低估/合理/高估 |
| EV/EBITDA | \_\_ 倍 | 6-10 | 低估/合理/高估 |

> **至少两个指标指向"低估"，且周期位置判断在"底部区间"，才考虑逆周期配置。**

## 周期型公司快速参照

### 典型周期行业及其正常化 PE 中枢

| 行业 | 正常化 PE 中枢 | PB 中枢 | 周期长度 |
|:---|:---:|:---:|:---|
| 钢铁 | 10-14× | 0.8-1.2× | 3-5 年 |
| 水泥 | 12-16× | 1.0-1.5× | 3-5 年 |
| 化工 | 12-18× | 1.2-2.0× | 3-5 年 |
| 航运 | 8-12× | 0.8-1.5× | 5-10 年 |
| 生猪养殖 | 15-20× | 2.0-4.0× | 3-4 年 |
| 有色金属 | 12-18× | 1.0-2.0× | 5-8 年 |

### 逆周期配置节奏

```
确认底部区间 → valuation，30% 计划买入
财报或行业数据确认周期未继续恶化 → evidence，30%
价格止跌且库存/价格信号改善 → stabilization，25%
周期反转得到验证 → catalyst，15%
确认景气回升 → 持有等待
景气顶峰信号出现 → 逐步减仓
```

> 分批比例与 [../SKILL.md](../SKILL.md) 第五步一致（30 / 30 / 25 / 15）。这里只估计节奏，不计算标的总仓位或最大仓位。
