## 阶段四：决策

| 质地 | 估值 | 决策 |
|:---|:---|:---|
| ⭐⭐⭐ | 低估 | ✅ 买入，分批建仓 |
| ⭐⭐⭐ | 合理 | 👀 观察列表，等回调 |
| ⭐⭐⭐ | 高估 | ⏸️ 暂时跳过 |
| ⭐⭐ | 明显低估 | ⚠️ 小仓位试探 |
| ⭐⭐ | 合理/高估 | 👀 等待 |
| ⭐ | 任何 | ❌ 排除 |

### 基础仓位（「基础仓位 × 调整因子」里的第一项，全流程唯一口径）

表中是**起步区间**，同一格内按波动率、确定性与周期位置取值，并在报告里写明取的是哪一格、为什么：

| 质地 | 低估 | 合理 | 高估 |
|:---|:---:|:---:|:---:|
| ⭐⭐⭐ 优质 | 5–10% | 4–8% | 1–2% |
| ⭐⭐☆ / ⭐⭐ 有瑕疵但可接受 | 2–5% | 2–5% | 0–1% |
| ⭐ 排除 | 0% | 0% | 0% |

> 表格填法：基础仓位 = 上表查得的起步值；最终仓位 = 基础仓位 × 调整因子（高波动 0.7 / 高相关 0.6 / 流动性差 0.5 / 认知深 1.2 / 有催化 1.3），再与单标的上限取较小值——个股按质地分档：**优质 ≤ 12%、有瑕疵 ≤ 5%，其中年化波动 > 40% 的周期股一律 ≤ 5%**；ETF 行业/金融 ≤ 15%、宽基 ≤ 25%。
> 「合理」档拿到的是**回调到位后可以拿住的目标底仓**，不是现价就买满；决策表里的「观察 / 等待」指这一步先不下单，触价后再按下面的节奏分批。
