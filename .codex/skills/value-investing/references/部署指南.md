# 部署指南 —— 价值投资估值 Skill（Codex 版）

> 本文说明怎么把这份 Skill 装到 Codex 全局、怎么验证、怎么改。

---

## 一、Codex 怎么发现 Skill

Codex 从两个位置发现 Skill：

| 位置 | 作用范围 |
|:---|:---|
| `~/.codex/skills/<skill-name>/SKILL.md` | 全局，所有项目可用 |
| `<项目根>/.codex/skills/<skill-name>/SKILL.md` | 仅当前项目 |

本机是 Linux，`~` 即 `/home/<用户名>`，所以全局位置是：

```
/home/canon/.codex/skills/value-investing/
├── SKILL.md                     ← 入口，必读
├── agents/openai.yaml           ← UI 显示名与默认提示词
├── scripts/cache.py             ← 通用数据的本地缓存读写
├── scripts/scorecard.py         ← 数据卡与 presentation 校验
└── references/                  ← 方法、数据卡与 Web 区块规范
```

报告输出到当前工作目录；通用数据缓存在工作目录的 `common/` 下，由技能在取数时自动创建，不随技能目录分发。

发现规则和 Claude Code 不同：**Codex 技能的入口文件必须叫 `SKILL.md`，且技能名以目录名/`name` 字段为准**，不是文件名。Frontmatter 里的 `name` 与 `description` 决定它何时被自动选中。

## 二、安装

技能包目录本身就是要安装的内容，复制到全局技能目录即可：

```bash
rm -rf ~/.codex/skills/value-investing
cp -r ./value-investing ~/.codex/skills/value-investing
```

先删旧目录再复制，所以可以反复执行来更新版本；只想改单个文件时，也可以直接 `cp` 覆盖对应文件。

技能目录按 Codex 约定解析：**优先 `$CODEX_HOME/skills`，未设置时用 `~/.codex/skills`**。要装到别处就临时设环境变量，例如 `CODEX_HOME=/tmp/codex-test cp -r ./value-investing /tmp/codex-test/skills/`。

只想在某个项目里用，就复制到 `<项目根>/.codex/skills/` 下。

## 三、验证是否加载

```bash
find ~/.codex/skills/value-investing -type f
head -5 ~/.codex/skills/value-investing/SKILL.md
```

然后在 Codex 里直接说「给招商银行估值」，或显式调用 `$value-investing`。能正常开始查数据、最后生成并校验 `data/{名称}_{日期}.json`，就说明生效了。

### 用官方脚本校验（可选）

```bash
python3 ~/.codex/skills/.system/skill-creator/scripts/quick_validate.py \
        ~/.codex/skills/value-investing
```

通过时输出 `Skill is valid!`。脚本依赖 PyYAML，缺了就 `pip3 install pyyaml`（需要网络）。

## 四、怎么改

| 想改什么 | 改哪个文件 |
|:---|:---|
| 数据卡 ranking 字段 | `references/数据卡规范.md` |
| Web 详情页区块和图表语义 | `references/报告区块规范.md` |
| 触发时机与整体流程 | `SKILL.md` |
| 估值参数与阈值 | 对应路径的 `references/*估值.md` |
| 数据搜索策略 | `SKILL.md` 第一步 |
| 通用数据的缓存范围、字段格式与有效期 | `references/本地数据缓存.md` 与 `scripts/cache.py` |
| 新增估值路径（如 REITs） | 新增一个 reference，并在 `SKILL.md` 的分类表与路由里加一行 |

改完 `SKILL.md` 与 `references/` 立即生效，无需重启。

## 五、常见问题

**Q：为什么我没有触发这个技能？**
A：检查三件事：目录是否在 `~/.codex/skills/` 下、入口文件是否叫 `SKILL.md`、frontmatter 是否完整。自动触发依赖 `description`，显式调用用 `$value-investing`。

**Q：技能之间能互相调用吗？**
A：不能嵌套调用。本技能用「主文件 + `references/` 分档」的方式组织：`SKILL.md` 是流程指挥，细节按需读取对应参考文档，避免一次把全部内容塞进上下文。

**Q：为什么不再生成 HTML？**
A：HTML 再由后端解析会把自然语言和 DOM 结构变成隐式协议。现在统一输出 JSON，排名和 Web 详情页共享同一份结构化数据。

**Q：想支持美股 / 港股？**
A：在 `SKILL.md` 第一步的数据搜索策略里补充数据源（美股用 SEC EDGAR、Yahoo Finance；港股用披露易、AASTOCKS），并在报告页脚注明数据源。

**Q：能不能定时跑？**
A：本技能本身不做定时。需要定期跟踪观察列表时，用 Codex 的定时任务/自动化功能另行配置，让它在固定时间调用本技能。

**Q：搜不到数据怎么办？**
A：立即终止本次估值并报告缺失字段，不生成数据卡。不得使用估计值、历史值、过期缓存或“未获取”占位继续。
