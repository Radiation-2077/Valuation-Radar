# 粗筛与质地判断

> 阶段一参考文档。判断一家公司是不是"好公司"——与行业、周期位置无关。

---

## 一、会计质量

### 1.1 利润真实性

$$质量比 = \frac{经营现金流}{净利润}\quad\text{（取近 3 年均值）}$$

| 比值 | 含义 |
|:---|:---|
| > 1.0 | 优秀：赚的是真金白银 |
| 0.8-1.0 | 正常 |
| < 0.8 | ⚠️ 利润可能变成了应收账款或存货 |
| < 0.5 | 🔴 危险：利润几乎全是纸面数字 |

### 1.2 非经常项目

$$占比 = \frac{非经常性损益}{净利润}$$

| 占比 | 含义 |
|:---|:---|
| < 10% | 正常 |
| 10-20% | ⚠️ 关注：是什么一次性项目？ |
| > 20% | 🔴 当前 PE 失真，必须用扣非净利润重算 |

### 1.3 审计意见

只接受"标准无保留意见"。任何其他意见 → 直接排除。

## 二、资产负债表

### 2.1 杠杆水平

$$有息负债率 = \frac{短期借款 + 长期借款 + 应付债券}{总资产}$$

| 水平 | 含义 |
|:---|:---|
| < 30% | 安全 |
| 30-50% | 中等，正常经营杠杆 |
| 50-60% | ⚠️ 偏高，关注利息覆盖 |
| > 60% | 🔴 高风险（金融业除外） |

### 2.2 短期偿债

$$流动比率 = \frac{流动资产}{流动负债}$$

| 水平 | 含义 |
|:---|:---|
| > 2 | 资金充裕 |
| 1-2 | 正常 |
| < 1 | ⚠️ 短期资金链紧张 |

### 2.3 利息覆盖倍数

$$利息覆盖 = \frac{EBIT}{利息费用}$$

| 水平 | 含义 |
|:---|:---|
| > 6 | 安全 |
| 3-6 | 正常 |
| < 3 | ⚠️ 经不起风吹草动 |

## 三、ROE 杜邦拆解

### 公式

$$ROE = \underbrace{\frac{净利润}{营收}}_{净利率} \times \underbrace{\frac{营收}{总资产}}_{资产周转率} \times \underbrace{\frac{总资产}{净资产}}_{权益乘数}$$

### 逐年拆解（填入近 5 年数据）

| 年份 | ROE | 净利率 | 周转率 | 权益乘数 | 备注 |
|:---|:---:|:---:|:---:|:---:|:---|
| Y-4 | | | | | |
| Y-3 | | | | | |
| Y-2 | | | | | |
| Y-1 | | | | | |
| 今年 | | | | | |

> **只用年度数（12-31）填这张表。** 中报 / 季报的营收、净利润、ROE 都是年初至今的**累计数**，直接填进来会让「今年」那一行的周转率、净利率腰斩（半年收入 ÷ 全年总资产），进而误判成经营恶化。要用中报就必须年化或换算 TTM，并在备注里写明口径。

### 解读要点

| 信号 | 含义 |
|:---|:---|
| 净利率 ↑ | 定价权增强或成本改善 → 好 |
| 净利率 ↓ | 竞争加剧或成本失控 → 警惕 |
| 周转率稳定 | 业务模式稳定 → 好 |
| 周转率大幅波动 | 并购/减值/战略变化 → 深究原因 |
| 杠杆 ↑ + 净利率 ↓ | 🔴 靠借钱维持 ROE → 危险 |

### 质量评分

| ROE 来源 | 评分 | 可持续性 |
|:---|:---:|:---|
| 高净利率（>15%）+ 低杠杆（<3×） | ⭐⭐⭐ | 极高 |
| 高周转（>1.5）+ 低杠杆 | ⭐⭐ | 高 |
| 高杠杆 + 高净利率 | ⭐⭐ | 中（看杠杆是否可控） |
| 高杠杆 + 低净利 + 低周转 | ⭐ | 低 |
| 三因子都平庸 | ❌ | 排除 |

## 四、护城河判断

| 类型 | 识别标志 | 财报特征 | 案例 |
|:---|:---|:---|:---|
| **品牌** | 消费者指名购买 | 高毛利率 + 低销售费用率 | 茅台、可口可乐 |
| **转换成本** | 客户换不掉 | 高续约率 + 高毛利率 | 微软、Adobe |
| **网络效应** | 越大越好用 | 份额持续扩大 | 微信、Visa |
| **成本优势** | 别人做不出来这个价 | 毛利率高于同行 | Costco、台积电 |
| **牌照/专利** | 政府给的护城河 | 高进入壁垒 | 免税龙头 |

### 关键测试

> 竞争对手拿 100 亿现金来打，能抢走多少份额？
> - 几乎抢不走 → 强护城河
> - 能抢 20-30% → 中等护城河
> - 轻松抢走一半 → 无护城河

## 五、生存能力

| 检查项 | 方法 | 红线 |
|:---|:---|:---|
| 压力年份盈利 | **最近一次**行业/宏观下行年份是否盈利？（如 2020 疫情、2022、2024–2025 行业下行，取离现在最近的一次） | 亏损 → 抗风险弱 |
| 压力年份 ROE | 同一次下行中 ROE 是否断崖？ | ROE 跌超一半 → 警惕 |
| 公司地位 | 国企/行业龙头？小公司？ | 小公司 + 高杠杆 → 危险 |
| 经营杠杆 | 固定成本 ÷ 总成本 | 高固定成本 → 收入下滑时利润垮得快 |

> 不要固定用 2020 年——离现在越远的年份越说明不了当前的抗压能力，选**最近一次**下行期，并在报告里写出用的是哪一年。

> **对周期型公司尤其重要**：周期型投资的核心逻辑是"在低谷买入，熬到回升"。如果熬不过去，就不是投资机会，是陷阱。
