# 安装指南 —— 价值投资估值 Skill（Codex 版）

项目级安装、开发账户、登录、验证、升级和故障排查统一维护在项目仓库的 `docs/CODEX_SKILLS.md`。

本文件只保留 Skill 自身的目录边界：

```text
value-investing/
├── SKILL.md
├── agents/openai.yaml
├── scripts/cache.py
├── scripts/scorecard.py
└── references/
```

开发时可以让 Codex 直接读取仓库内的 `.codex/skills/`；为保证后端 worker 在子目录执行任务时也能发现 Skill，建议给当前开发账户安装全局链接。安装时必须同时提供相邻的 `investment-ranking`，因为离线排序会加载本 Skill 的 schema 与校验脚本。

估值结果写入当前任务工作目录的 `data/`，通用数据缓存写入该目录的 `common/`。不要把这些运行产物写回 Skill 安装目录或数据库。

修改 `SKILL.md` 或 `references/` 后立即生效；修改脚本或 schema 后需同步运行后端、前端和类型检查。具体命令见项目仓库的 `docs/CODEX_SKILLS.md`。
