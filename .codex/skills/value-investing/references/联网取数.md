# 联网取数

第一步「数据收集」的取数环境与可复制命令。先读本文再动手，能省掉大量试错。

> 动手前先看 [本地数据缓存.md](本地数据缓存.md)：无风险利率、汇率、AH 溢价指数这类通用数据要先查工作区 `common/` 目录，命中且 24 小时内就直接用，未命中或过期才联网，抓到后回写。

## 一、先自检网络

环境是 Linux，命令行用系统自带的 `curl`。拉数前先做一次连通性自检，把「网络不通」和「接口取不到」区分开：

```bash
curl -s -m 10 -o /dev/null -w "%{http_code}\n" https://www.baidu.com
```

返回 `200` 说明网络正常；返回 `000` 且退出码非 0，说明连接被拦（Codex 沙箱断网时就是这个表现）。**不要反复重试**，先申请联网放行再取数，放行理由写清用途即可（例如「拉取 600036 行情与财务数据」）。

## 二、统一用 `curl`，显式加超时

每条命令都显式带超时，避免某个源卡住拖慢整轮取数：

- 常用参数：`-s` 静默、`-m 20` 超时 20 秒、`-o file` 落盘、`-w "%{http_code}"` 打印状态码。
- 新浪 `hq.sinajs.cn` 必须带 `-H "Referer: https://finance.sina.com.cn"`，否则 403。
- 需要解析 JSON、换算指标或批量交叉核对时改用 `python3`（见第五节）。

## 三、已验证的接口清单

A 股 secid 前缀：`1.` = 上交所(sh)，`0.` = 深交所(sz)；腾讯/新浪直接写 `sh`/`sz`。

```bash
curl -s -m 20 "https://qt.gtimg.cn/q=sh600036"
```

批量：`.../q=sz000858,sh600519`。返回 `v_sh600036="..."`，字段用 `~` 分隔（下标从 0 起）：

| 下标 | 含义 | 下标 | 含义 |
|:--|:--|:--|:--|
| 1 | 名称 | 38 | 换手率 % |
| 2 | 代码 | 39 | PE(TTM) |
| 3 | 现价 | 43 | 振幅 % |
| 4 | 昨收 | 44 | 流通市值(亿) |
| 5 | 今开 | 45 | 总市值(亿) |
| 30 | 时间戳 | 46 | PB |
| 31 | 涨跌额 | 47 / 48 | 涨停 / 跌停价 |
| 32 | 涨跌幅 % | 51 | 均价 |
| 33 / 34 | 最高 / 最低 | 52 / 53 | PE(动) / PE(静) |

### 1b) 腾讯 · 港股快照（**字段位置与 A 股不同，不要套用上表**）★A+H 必读

```bash
curl -s -m 20 "https://qt.gtimg.cn/q=hk00883"     # 港股写 hk + 5 位代码
```

港股返回值的**前半段**（现价、时间戳、涨跌幅、市值）与 A 股同位置，**第 46 位之后完全不同**：

| 下标 | 含义 | 下标 | 含义 |
|:--|:--|:--|:--|
| 1 | 名称 | 43 | 振幅 % |
| 2 | 代码 | 44 | 流通市值(亿，该市场股份 × 现价) |
| 3 | 现价 | 45 | 总市值(亿) |
| 4 | 昨收 | **46** | **英文名（不是 PB！）** |
| 5 | 今开 | 57 | **PE(TTM)** |
| 30 | 时间戳（`2026/10/12 16:08:24`） | 58 | **PB** |
| 31 / 32 | 涨跌额 / 涨跌幅 % | 59 | 换手率 % |
| 33 / 34 | 最高 / 最低 | | |

> ⚠️ A 股表里的 `39`（PE）、`46`（PB）、`47/48`（涨停跌停）、`52/53`（PE 动/静）**在港股全部不可用**：
> 港股的 46 位是英文名（如 `CM BANK`、`CCB`、`TENCENT`），39 位是另一种 PE 口径（实测与 TTM 差 2%–23%），港股没有涨停价字段。
> 用 A 股下标读港股会拿到"看起来像数字"的错误值（例如把 47 位的 `4.43` 当成 PB）。**港股一律用 57=PE、58=PB。**

**字段位置的复核方法（腾讯改版后照这个重验）**：同一家公司的 A/H 快照 + 汇率，H 的倍数应约等于 A 的倍数 × (H 价 ÷ HKD/CNY) ÷ A 价。2026-10-12 实测四例：

| 标的（A / H） | A 价 | H 价 | A 的 PE / PB | 预测 H 的 PE / PB | 实测 H 的 idx57 / idx58 |
|:--|:--|:--|:--|:--|:--|
| 招商银行 600036 / 03968 | 42.76 | 53.80 | 7.11 / 0.94 | 7.63 / 1.01 | 7.77 / 1.03 |
| 中国平安 601318 / 02318 | 53.24 | 51.65 | 6.05 / 0.95 | 5.01 / 0.79 | 5.10 / 0.79 |
| 比亚迪 002594 / 01211 | 84.60 | 74.35 | 26.21 / 3.21 | 19.65 / 2.41 | 20.00 / 2.45 |
| 建设银行 601939 / 00939 | 11.31 | 9.91 | 8.54 / 0.83 | 6.38 / 0.62 | 6.50 / 0.63 |

四例误差 1.4%–2.4%，可确认 57 / 58 就是 PE / PB。差异 > 5% 时先怀疑字段位变了，不要直接写进报告。

### 1c) ETF 净值、完整成分权重与组合 PB

ETF 行情可用腾讯；基金份额净值从基金净值接口获取：

```bash
curl -s -m 20 -A "Mozilla/5.0" -H "Referer: https://fundf10.eastmoney.com/" \
  "https://api.fund.eastmoney.com/f10/lsjz?fundCode=513090&pageIndex=1&pageSize=5"
```

返回 `Data.LSJZList[0].FSRQ` 为净值日期、`DWJZ` 为份额净值。`price / nav - 1` 才是 ETF 折溢价，不是 PB。

中证指数完整样本权重与估值文件：

```bash
curl -s -m 20 -A "Mozilla/5.0" \
  "https://www.csindex.com.cn/csindex-home/indexInfo/index-details-data?fileLang=2&indexCode=930709"
```

可从 `top10new` 获取前十大权重，也可从返回的 `样本权重`、`样本列表`、`指数估值` 下载 `.xls` 文件交叉核对。前十大代表 PB 先按所列权重归一化，再计算调和平均：

```text
PB_top10 = coverage_pct / Σ(weight_i ÷ PB_i)
```

结果只代表前十大成分，不是全指数精确值；必须记录 `coverage_pct`。每只成分的 PB 与权重日期必须分别记录；ETF 折价/溢价和底层代表 PB 是两个独立指标。

### 2) 东方财富 · 财务数据（数据中心）★首选

主要财务指标（营收、净利、ROE、每股净资产、股息率…）：

```bash
curl -s -m 20 "https://datacenter-web.eastmoney.com/api/data/v1/get?reportName=RPT_LICO_FN_CPD&columns=ALL&filter=(SECURITY_CODE%3D%22600036%22)&pageSize=6&sortColumns=REPORTDATE&sortTypes=-1"
```

关键字段：`REPORTDATE` 报告期、`TOTAL_OPERATE_INCOME` 营收、`PARENT_NETPROFIT` 归母净利、`WEIGHTAVG_ROE` 加权 ROE、`BASIC_EPS` 每股收益、`DEDUCT_BASIC_EPS` 扣非 EPS、`BPS` 每股净资产、`YSTZ` 营收同比 %、`SJLTZ` 净利同比 %、`MGJYXJJE` 每股经营现金流、`ZXGXL` 最新股息率 %、`ASSIGNDSCRPT` 分红方案。

> ⚠️ **报告期口径**：`REPORTDATE` 是**报告期末**，同一行里的营收、净利润、`WEIGHTAVG_ROE` 都是**年初至该期末的累计数**。实测该接口最新一行是 `2026-06-30`、`WEIGHTAVG_ROE = 6.71`——那是**半年** ROE，不是年 ROE。
> 处理方式：TTM = 上年年报 − 上年同期 + 本期；ROE 趋势、杜邦拆解、股息率分母一律只用 `12-31` 的行；引用中报数据时在报告里写明「20XX 中报，累计数」。

分红历史：把 `reportName` 换成 `RPT_SHAREBONUS_DET`。

### 4) 历史 K 线 · 腾讯 `fqkline` ★首选

```bash
# A 股日 K（前复权，最近 320 根）；港股同理换 hk00883；月 K 把 day 换成 month
curl -s -m 20 "https://web.ifzq.gtimg.cn/appstock/app/fqkline/get?param=sh600036,day,,,320,qfq"
```

返回 `data.<代码>.<键>`，数组每条为 `日期,开,收,高,低,成交量`。**键名随代码与周期变化**：A 股前复权是 `qfqday` / `qfqmonth`，港股返回的是 `day` / `month`（没有 `qfq` 前缀）。解析时按「先取 `qfq<周期>`，没有再退回 `<周期>`」写，不要写死键名。（A/H 历史溢价用月 K，见 [AH与跨市场估值.md](AH与跨市场估值.md)。）

## 四、多源交叉验证

框架要求 PE、ROE 至少两个来源。最省事的组合：

- **价格**：腾讯 vs 新浪（同一时刻两者必然一致，不一致就是解析错了——不要拿文档里的旧数值当预期，行情每天在变）；
- **PE / PB / ROE**：腾讯快照 vs 东方财富数据中心；
- **财务**：东方财富数据中心 `RPT_LICO_FN_CPD` 为主。

**港股 PE / PB 的一致性检查**：腾讯港股快照（57 / 58 位）算出的倍数，应与「A 股快照倍数 × (H 价 ÷ HKD/CNY) ÷ A 价」吻合（方法见 1b）。必需数字只能取到一个来源或两源冲突时立即终止，不得降低置信度后继续。

必需数据取不到时立即终止并报告字段；不得用「未获取」、估算或历史值继续出卡。

## 五、Python 兜底（可选）

取数优先用 `curl`；需要解析 JSON、换算指标或批量核对时再用 `python3`（本机 3.12，已装 `requests`）。

```python
import requests

r = requests.get("https://qt.gtimg.cn/q=sh600036", timeout=10)
r.encoding = "gbk"          # 腾讯返回 GBK
p = r.text.split("~")
print(p[1], p[3], "PE", p[39], "PB", p[46])   # 招商银行 42.76 PE 7.11 PB 0.94
```

缺库时 `pip3 install <包名>` 即可（联网同样需要放行）。不要用 `akshare` 这类重型库兜底，接口本身已经够用。

## 六、常见报错对照

| 现象 | 原因 | 处理 |
|:--|:--|:--|
| `http_code` = `000`，退出码非 0 | 沙箱断网 | 申请放行后重试 |
| 退出码 56 / 返回空 | 源站限流或波动 | 换源兜底（腾讯 / 新浪） |
| 新浪 403 | 缺 Referer | 加 `-H "Referer: https://finance.sina.com.cn"` |
| 港股 PE / PB 明显不合理（如 PB > 5 或为字符串） | 用了 A 股的字段下标 | 按 1b 的港股表取 57 / 58 位 |
| 财务指标只有半年数值 | 取到了中报行（`REPORTDATE` 为 `06-30`） | 按 TTM 换算，或只取 `12-31` 的行 |
