# Web 报告区块规范（presentation）

`presentation` 是数据卡中的页面语义层。模型只输出章节、控件类型和数值，Web 前端负责布局、圆角、颜色、图表尺寸、tooltip 和响应式。

## 顶层结构

```json
{
  "presentation": {
    "schema_version": "1.0",
    "sections": [
      {
        "id": "quality",
        "title": "一、标的质地",
        "market": "common",
        "blocks": []
      }
    ]
  }
}
```

- `sections[]` 必须非空，`id` 在一个数据卡内唯一。
- `market` 取 `common` / `A` / `H` / `US` / `CN`；两地共用章节写 `common`。
- 每个业务 section 最后必须有一个 `callout` 块，并设置 `"summary": true`。
- 不输出 CSS、HTML、SVG、class、组件路径或像素尺寸。

## A/H section 契约

A+H 数据卡必须逐市场拆章，禁止把 A/H 的价格、估值、仓位或预期收益混在同一 section：

- `dashboard-A` / `dashboard-H`
- `quality`、`cycle`、`cross_market`、`sources`、`disclaimer` 使用 `market: "common"`
- `valuation-A` / `valuation-H`
- `position-A` / `position-H`
- `expected_return-A` / `expected_return-H`
- `risks-A` / `risks-H`
- `conclusion-A` / `conclusion-H`

`cross_market` 只回答「溢价是否合理」，允许使用溢价公式、税负/利率差表格、`bullets`、`premium_donut` 和本章小结。不得放入单市场估值表、情景、合理区间、仓位档位或收益拆解。

## 通用块

```json
{"type":"heading","level":3,"text":"质量分项评分（0–10）"}
{"type":"paragraph","text":"正文","note":false}
{"type":"callout","tone":"info","title":"本章小结","body":"结论与操作含义","summary":true}
{"type":"table","headers":["维度","结果","评价"],"rows":[["ROE","13.0%","中上"]]}
{"type":"formula","latex":"\\frac{D}{P_A}(1-t_A)+g=\\frac{D}{P_H}(1-t_H)+g","caption":"同一现金流下，A/H 税后股息率应相等"}
{"type":"bullets","items":["高股息标的受税费差影响更大","低股息、高成长标的受影响较小"]}
```

`tone` 只能是 `pos` / `warn` / `neg` / `info`。

正文、表格单元格和 `callout` 可使用受控的行内格式：

- `**重点内容**` 显示为加粗；
- `` `DGS10` `` 显示为行内代码；
- `\(...\)` 显示为行内数学公式。

独立成行、需要完整展示的推导必须使用 `formula` 块，不把大段 LaTeX 塞进段落。复杂公式只写在 `latex` 字段，说明写在 `caption`。

## 质量评分区块

质量章固定使用一个两栏 `grid`，左栏 `scores`，右栏 `table`。不得新增质量专用控件。

```json
{
  "type": "grid",
  "columns": [
    [
      {"type": "heading", "level": 3, "text": "质量分项（0–10）"},
      {
        "type": "scores",
        "items": [
          {"label": "利润现金含量", "score": "9.0", "width": 90, "tone": "positive"},
          {"label": "资产负债表", "score": "8.0", "width": 80, "tone": "positive"},
          {"label": "ROE 水平", "score": "9.0", "width": 90, "tone": "positive"},
          {"label": "护城河强度", "score": "8.5", "width": 85, "tone": "positive"},
          {"label": "生存能力", "score": "8.0", "width": 80, "tone": "positive"}
        ]
      }
    ],
    [
      {"type": "heading", "level": 3, "text": "关键指标"},
      {
        "type": "table",
        "headers": ["维度", "结果", "评价"],
        "rows": [
          ["经营现金流 / 净利润", "1.9 倍", "真实"],
          ["有息负债率", "16.1%", "较低"],
          ["ROE（近 3 年均值）", "24.4%", "优秀"],
          ["护城河", "规模 + 技术 + 成本", "强"],
          ["压力年份（2022 原材料冲击）", "归母净利 307 亿元", "通过"]
        ]
      }
    ]
  ]
}
```

硬性要求：五个 `scores` 维度顺序固定；`width = score × 10`；右侧三列表格固定五行并与左侧逐行对应。

## 仓位档位

```json
{
  "type": "position_tiers",
  "market": "A",
  "target_position_pct": 6.0,
  "cap_pct": 12,
  "items": [
    {"level":1,"price":232.74,"allocation_pct":40,"active":true},
    {"level":2,"price":210,"allocation_pct":30,"active":false},
    {"level":3,"price":198,"allocation_pct":30,"active":false}
  ]
}
```

`allocation_pct` 是“占目标仓位的比例”，三档必须合计 100；`target_position_pct` 才是“占资产比例”。禁止用 `"加至 3%"` 之类的自然语言代替 `allocation_pct`。

## 收益拆解

```json
{
  "type": "return_stack",
  "market": "A",
  "items": [
    {"source":"growth","label":"增长","value_pct":8.0},
    {"source":"dividend","label":"股息","value_pct":4.3},
    {"source":"valuation","label":"估值修复","value_pct":15.6},
    {"source":"fx","label":"汇率","value_pct":0}
  ],
  "total_pct": 27.9
}
```

`source` 只能是 `growth` / `dividend` / `valuation` / `fx`。图例和颜色由前端根据 `source` 决定。

## A/H 溢价分解

```json
{
  "type": "premium_donut",
  "market_pair": ["A","H"],
  "total_premium_pct": -27.5,
  "items": [
    {"label":"贴现率差","contribution_pct":14,"share_pct":21,"tone":"blue"},
    {"label":"市场分割与筹码","contribution_pct":-47,"share_pct":71,"tone":"gold"},
    {"label":"股息税差","contribution_pct":5,"share_pct":8,"tone":"green"},
    {"label":"残余（真实相对贵贱）","contribution_pct":0.5,"share_pct":1,"tone":"red"}
  ]
}
```

`share_pct` 合计 100。`contribution_pct` 是百分点贡献，不能与 `share_pct` 混用。

## 风险与结论

```json
{
  "type":"risk_cards",
  "items":[
    {
      "scope":"common",
      "market":null,
      "title":"Q3 毛利率压缩继续",
      "severity":"high",
      "body":"风险传导路径",
      "mitigation":"跟踪与应对动作"
    }
  ]
}
```

`severity` 只能是 `high` / `medium` / `low`；前端负责显示“高 / 中 / 低”。禁止输出 `lv-h` 等内部缩写。
