# AH 溢价与跨市场估值

> 适用场景：同一家公司在 A 股与港股（H 股 / 红筹 / 中概）同时上市时，判断「该买哪个市场」「溢价是否合理」。
> 触发条件：标的同时有 A 股代码与港股代码（如 600938.SH / 00883.HK、600036.SH / 03968.HK、601318.SH / 02318.HK）。

---

## 一、核心原则：不能只比绝对价格

$$A/H 比价 = \frac{A 股价}{H 股价 \times HKD/CNY} \qquad A/H 溢价 = 比价 - 1$$

这个比价**只是名义溢价**。两个市场在**税收、贴现率、流动性、投资者结构**上系统性不同，因此存在长期、结构性的合理溢价。

**把名义溢价直接当成「H 股便宜 40%、可以套利」是典型错误。** 结构性折价可能十年不收敛。

### 前置校验原则（强制顺序）

**跨市场溢价校验必须排在估值分析之前，作为独立一章；「低估 / 合理」的结论要在校验完成之后才给出。**

理由：

- H 股看起来「更便宜」的幅度里，很大一部分是结构性折价（股息税、贴现率、市场分割），**不是额外的安全边际**；
- 若不先扣除，会系统性放大 H 股的「便宜程度」，同时低估 A 股的相对偏贵；
- 报告的估值章节必须**显式引用**本校验的结论（例如「上述低估/合理判定已在上章完成跨市场校验后进行」）。

**报告章节顺序**：一、标的质地 → 二、产业周期定位 → **三、跨市场校正** → 四、A 股估值 → 五、H 股估值 → 六、操作建议与仓位管理 → 七、预期收益率 → 八、风险提示 → 九、关键结论。

> 这是 A+H 标的专用的 section 顺序。写入 `presentation.sections[]` 时使用稳定 `id`：`dashboard`、`quality`、`cycle`、`cross_market`、`valuation-A`、`valuation-H`、`position`、`expected_return`、`risks`、`conclusion`、`sources`。

## 二、四类结构性因素（按对溢价的影响排序）

### ① 股息税差（对高股息标的权重最大）

| 持有方式 | 红利税负 |
|:---|:---:|
| A 股，个人持有 > 1 年 | 0% |
| A 股，个人持有 1 个月–1 年 | 10% |
| A 股，个人持有 < 1 个月 | 20% |
| H 股，内地个人经港股通持有 | 20% |
| H 股，内地个人经香港券商直接持有 | 10% |
| H 股，内地企业经港股通持有满 12 个月 | 0%（免征） |
| A 股，内地居民企业 | 0%（居民企业间股息免税） |

**税负等价比价 = (1 − t_A) ÷ (1 − t_H)**

推导（关键：红利税只影响分红，不影响资本利得——两地个人资本利得均免征，所以增长项 g 在两边相同、可约掉）：

$$\frac{D}{P_A}(1-t_A) + g = \frac{D}{P_H}(1-t_H) + g \;\Longrightarrow\; \frac{P_A}{P_H} = \frac{1-t_A}{1-t_H}$$

| 投资者类型 | 合理比价 | A 合理溢价 |
|:---|:---:|:---:|
| 个人长期（A 0% vs H 20%） | 1.25 | +25% |
| 个人（A 0% vs H 10%） | 1.11 | +11% |
| 企业免税（0% vs 0%） | 1.00 | 0% |

> 推论：**股息率越高的标的，税费差对合理溢价的影响越大**；低股息/高成长标的受影响小。
> 红利税政策以税务机关最新口径为准（A 股差别化个人所得税、港股通股息红利代扣政策），政策变动会直接改变「合理溢价」。

### ② 贴现率差（无风险利率差）

H 股以港元/美元定价，边际投资者（国际资金）用**美元无风险利率**贴现；A 股投资者用**人民币利率**。当美元利率显著高于人民币利率时，同一现金流在 H 股被要求更高回报 → H 股估值系统性更低 → A 溢价扩大。

- 传导量级：贴现率每高 2–3pct，对长久期资产估值影响约 15–25%。
- 取值：美国 10 年期国债（FRED `DGS10`）vs 中国 10 年期国债（中债估值；取不到时用中金所国债期货 T 主力隐含收益率推算）。

### ③ 市场分割与筹码稀缺

- 资本管制：内地资金不能自由出境，A 股可选资产有限 → 相对溢价。
- 自由流通盘：部分 A 股（尤其新上市的国企）自由流通盘占比极低，筹码稀缺 → 溢价。
- 刚性配置需求：A 股纳入指数、险资/公募的被动与主动配置。

### ④ 投资者结构与情绪

- A 股：散户占比高、换手率偏高、主题/红利风格抱团，对高股息定价可能偏高。
- H 股：机构/外资占比高，对传统能源、国企、ESG 给予折价。
- 南向资金（港股通）持续净买入会**收窄**溢价；外资流出会**扩大**折价。

## 三、标准工作步骤

1. **取价与汇率**：两边股价 + HKD/CNY（或 USD/CNY ÷ USD/HKD）→ 算名义比价与溢价。
2. **还原历史溢价**：用两地月 K 线 + 对应月份汇率，至少覆盖 3–5 年，判断当前溢价处于历史什么位置（高/中/低分位）。
3. **逐项拆解**：
   - 税负等价比价（给出合理溢价下限）
   - 叠加贴现率差（用中美 10 年期利差粗估）
   - 叠加市场分割/筹码稀缺
   - 得到「结构性合理溢价」区间
4. **求残余**：名义溢价 − 结构性合理溢价 = 真实的「A 相对贵 / H 相对便宜」幅度。
5. **分投资者类型给结论**（个人长期 / 个人短期 / 机构 / 企业），因为税负不同，结论可能相反。

---

## 四、结论写法（重要）

**不要写**：「H 股比 A 股便宜 40%，买入 H 股套利。」

**要写**：「名义 A/H 溢价 66%，其中约 50 个百分点可由股息税（+25）、贴现率差（+15~20）、市场分割与筹码稀缺（+10~15）解释，属长期结构性问题；剔除后可解释部分，A 股相对 H 股仍高估约 10–20pct。因此配置 H 股的理由是**更高的税后股息 + 更低的估值**，而不是等溢价收敛赚差价。」

**溢价收敛的前提条件**（需同时或多个出现）：

- 人民币利率上行 / 美元利率下行（利差收窄）
- 资本账户进一步开放、资金自由流动
- 南向资金持续大幅净流入
- A 股发行制度改革（如大量增发、扩大流通盘）

**要显式标注不确定性与政策依赖**：红利税政策、互联互通额度规则、汇率制度都可能变化。

## 六、实务提醒

- **同一资产、同一现金流、同一管理层**，两地价差只可能来自制度与投资者差异，不来自基本面。
- **不要把结构性折价计入预期收益**：做 H 股收益率测算时，用「税后股息 + 盈利增长 + 估值修复」，不要加「溢价收敛」这一项。
- **反向也要检查**：当 H 股相对 A 股大幅折价时，也可能是 H 股市场流动性差、被指数剔除、或存在治理/退市风险，而非单纯便宜。
- **红筹/非 H 股**（注册在境外、香港上市）与 **H 股**（注册在内地、香港上市）的红利税与公司治理不同，须分别判断。

## 七、可视化：溢价成因比例圆环（推荐）

数字表之外，使用 `premium_donut` 复合块表达「每一成因占绝对影响总额的比重」。不要输出 CSS、conic-gradient 或 SVG。

```json
{
  "type": "premium_donut",
  "market_pair": ["A", "H"],
  "total_premium_pct": 66,
  "items": [
    {"label": "股息税差", "contribution_pct": 25, "share_pct": 38, "tone": "blue"},
    {"label": "贴现率差", "contribution_pct": 18, "share_pct": 27, "tone": "blue"},
    {"label": "市场分割与筹码", "contribution_pct": 12, "share_pct": 18, "tone": "gold"},
    {"label": "残余（真实相对贵贱）", "contribution_pct": 11, "share_pct": 17, "tone": "red"}
  ]
}
```

要点：

- 圆环中心由前端读取 `total_premium_pct`；
- `share_pct` 合计必须为 100，`contribution_pct` 保留原始百分点；
- 明细表继续保留“占溢价 %”和“对应 pct”两列；
- 残余项使用 `tone: "red"`，并明确它是唯一计入「H 股低估 / A 股高估」的部分。

## 八、A+H section 必须彻底分市场

只要标的有 H 股，估值部分就**必须拆成两章、分市场各做一遍**，不要在同一张表里混排两地数据：

- 「四、A 股估值」：只放 A 股的指标、情景、合理区间；
- 「五、H 股估值」：只放 H 股的指标、情景、合理区间；
- 跨市场的并列数据**只出现在「三、跨市场校正」一章**（那是它的主题），其余章节一律分章或分行，不混排。

对应的 `presentation` section 固定为：

- `dashboard-A` / `dashboard-H`
- `quality` / `cycle` / `cross_market`（`common`）
- `valuation-A` / `valuation-H`
- `position-A` / `position-H`
- `expected_return-A` / `expected_return-H`
- `risks-A` / `risks-H`
- `conclusion-A` / `conclusion-H`

`cross_market` 只做溢价比较，不允许出现 `valuation_scenarios`、`range_position`、`position_tiers` 或 `return_stack`。

两章各自必须包含：

1. 该市场的估值指标表（正常化 PE、PB、PB÷ROE、EV/EBITDA、税后股息率），基准与信号列只对该市场；
2. 该市场的情景柱状图 + 情景表；
3. 该市场的合理估值区间标尺 + 一段「本章小结」；
4. 两章必须使用**同一套正常化 EPS 假设**——若倍数假设不一致，说明哪里算错了。

计算与写法：

- H 股股价（港币）= 正常化 EPS（人民币）× H 股合理 PE ÷ HKD/CNY；
- 涨跌幅分别相对**各自现价**计算（不要用 A 股现价当基准）；
- 必须写清：**H 股使用的倍数低于 A 股，反映的是结构性折价，不应再当作额外安全边际**；
- 同时持有 A+H 时，在仓位章说明「属于同一风险敞口，仓位合并计算」。

> 若两个市场合理区间的中枢差异过大（例如 H 股中枢比 A 股低 40% 以上），先回到溢价分解章检查结构性因素是否已解释，否则说明倍数假设不一致。

**首屏结论按两地分开存储**：`markets[A].verdict` 与 `markets[H].verdict` 只写方向；更长的判断放在 `presentation` 的 `dashboard` / `conclusion` 章节。市场标识写进结论词（如 `A 分批买入`、`H 观望`），不要在 verdict 字符串里塞价格、PE、布局或多个句子。

## 九、每章小结的写法

每个章节结尾都要加一个 `type: "callout"` 且 `summary: true` 的块，一到两句说清：**这章得出什么结论 + 对操作意味着什么**。不要把结论埋在普通段落里。

| 章节类型 | 小结要写清什么 |
|:---|:---|
| 公司层面（质地、产业周期） | 结论 + 注明「A 股与 H 股共用，差异只在估值倍数」 |
| 跨市场校正 | 结构性溢价与残余各占多少 + 「本章是后续估值结论的前置条件」 |
| A 股估值 / H 股估值 | 该市场的贵贱判断 + 合理区间与中枢 + 是否已扣除结构性折价 + 买点 |
| 操作与仓位 | 两地各自的目标仓位与分批节点 + 合并上限 |
| 预期收益率 | 两地各自年化 + 差额来源（是股息与估值起点，而不是溢价收敛） |
| 风险提示 | 区分「共同风险」与「市场间风险」，并给两地各自的最大回撤 |
