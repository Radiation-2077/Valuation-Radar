# 稳定增长型估值

> 阶段三A 参考文档。适用条件：利润波动小（年波动 < 15%）、与 GDP 弱相关、持续盈利且分红。

---

## 核心工具：Gordon 反推

不判断"PE 高不高"，而是**反推市场隐含的增长率，问自己这个增长率是否合理**。

### 公式

$$PE = \frac{p}{r - g} \quad\Longrightarrow\quad g = r - \frac{p}{PE}$$

| 符号 | 含义 | 怎么取值 |
|:---|:---|:---|
| $PE$ | 当前市场市盈率 | 行情软件 PE-TTM（扣非） |
| $p$ | 分红率 | 近 3 年总分红 ÷ 近 3 年总净利润 |
| $r$ | 你要求的年回报率 | 10 年期国债 + 风险溢价（稳定公司 3-5%） |
| $g$ | **反推结果** | 市场认为的长期永续增速 |

### 操作步骤

**第 1 步：取 PE**

```
当前 PE = ______ 倍（确认是扣非 TTM）
```

**第 2 步：算分红率**

```
近 3 年总分红 = ______ 亿
近 3 年总净利润 = ______ 亿
p = 总分红 ÷ 总净利润 = ______ %
```

**第 3 步：设定 r**

```
当前 10 年期国债收益率 = ______ %
风险溢价 = ______ %（建议 3-5%，确定性越高溢价越低）
r = ______ %
```

**第 4 步：反解 g**

```
g = r − p/PE = ______ % − ______ % / ______ = ______ %
```

## 解读：隐含增长率是否合理？

| 对比 | 含义 | 操作 |
|:---|:---|:---|
| 你的判断 > 市场 g | 市场低估 | 👉 可能有机会 |
| 你的判断 ≈ 市场 g | 定价合理 | 👉 安全边际不够 |
| 你的判断 < 市场 g | 市场太乐观 | 👉 太贵 |

### 如何形成你自己的 g 判断？

**方法一：自上而下**
$$g = 行业增速 \times 公司份额变化 \times 利润率变化 + 回购贡献$$

**方法二：自下而上（可持续增长率）**
$$g = ROE \times (1 - p)$$
取保守值——ROE 不会永远维持高位，用近 5 年均值的 80% 代入更现实。

**方法三：历史参照**
该公司过去 5-10 年实际利润复合增速是多少？未来和过去会有什么不同？

**最终取值**：取三个方法中的偏保守数字。

## PEG 交叉验证

$$PEG = \frac{PE}{你判断的长期增速}$$

**先定基准再比**：把 Gordon 式子 $PE = p / (r-g)$ 代进 PEG 就能看出，合理 PEG 的水平几乎只由**分红率**决定——在 r=8% 下，理论合理 PEG ≈ **2 × p**（g 取 3–6% 时都成立）：

| 分红率 p | 理论合理 PEG（r=8%） | 低估参考 | 偏贵参考 |
|:---|:---:|:---:|:---:|
| 20–30% | 1.8–2.0 | < 1.4 | > 2.6 |
| 40–50% | 2.8–3.3 | < 2.2 | > 4.3 |
| 60–70% | 4.0–4.7 | < 3.2 | > 6.1 |

> 两点必须记住：
> 1. **PEG=1 对高分红慢增长公司极其严苛**：p=50% 的公司合理 PEG 约 3.1，PEG=1 相当于要求它比合理水平便宜三分之二。反过来，p 只有 20–30% 的公司合理 PEG 就在 2 附近，用「PEG<1.5 才算便宜」这条通用阈值反而会放过贵的。
> 2. **不要用固定阈值**：上表按分红率分档用；只把 PEG 当**交叉参照**，主判断永远走 Gordon 反推（市场隐含 g 是否合理）。

## 股息率辅助判断

$$股息率 = \frac{每股分红}{当前股价}$$

| 信号 | 含义 |
|:---|:---|
| 股息率 > 国债收益率 | 光分红就已经跑赢国债 |
| 股息率连续 5+ 年增长 | 管理层回报股东的意愿可信 |
| 股息率突然跳升 | 可能是股价暴跌 → 排查基本面 |
